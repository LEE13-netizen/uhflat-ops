## 3. 관리자급

## 우선순위(효과 ÷ 작업량)
1. **재실 요청 한꺼번에 입력 + 청소·재실 호수 검색**(3년차·프론트, 효과 가장 큼)
2. **부서별 첫 화면**(키핑 → 내 방, 시설 → 작업대) + 현황판 조작 줄 접기(신입)
3. **안내 문구 숨기기**(3년차)
4. **담당별 진행 카드 + 관리자 담당 바꾸기**(관리자)
5. 용어집·첫 로그인 안내(신입)
6. 교대·마감(관리자, 큰 작업)
