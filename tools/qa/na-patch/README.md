# 야간 검수(NIGHT AUDIT) 24시 스테이 패치

OPS `js/seocho-ct.js`의 24시 스테이 인식과 같은 수정을 야간 검수 페이지(관리자용·직원용 index.html)에 넣는 6곳 교체(old_str → new_str).

- `24h-stay-edits.json`: 정확히 1번씩 나오는 문자열 교체 6개(관리자용·직원용 공통)
  1. 예약표 칸에 24시 표시(메모 "24시 스테이·24시간·24H·24 hours stay")와 입·퇴실 시각
  2. 예약표 읽은 뒤 24시 보정(두 칸 병합 → 1박, 예약 상세 박수 우선)
  3. 보조 함수(H24_RE · h24Times · apply24 · skyBlue · readFontBlue)
  4. 청소표 생성: 24시 퇴실 행에 "24시 스테이 — 퇴실 HH:MM", 같은 날 입실 겹침 경고, 오늘 입실 24시 표시
  5. 내보내기에 readFontBlue·apply24·h24Times
  6. 예약표 올린 뒤 하늘색 숫자 읽기(테두리 읽기 다음)
- 검증(사본): 24시 읽기 8/8 통과, 월·일 정산 시험대(시드 7·21) 결과가 패치 전과 완전히 같음, 페이지 오류 0
- 적용 후 예약표를 한 번 다시 올려야 24시 표시가 붙는다(저장된 예전 예약표에는 표시가 없음)
